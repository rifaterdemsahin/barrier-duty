## 🖼️ UI Mockups

The live site at `https://rifaterdemsahin.github.io/barrier-duty/` serves as the primary simulation of the intended solution.

Key screens:
1. **Home** — Welcome + call-to-action for availability updates
2. **Volunteer Rota** — Weekly table filtered by morning/afternoon
3. **Volunteers** — Directory and stats
4. **Updates** — Timeline of announcements
5. **Resources** — Video tutorial, duty rules, printable flier
6. **Admin** — Password-protected dashboard
